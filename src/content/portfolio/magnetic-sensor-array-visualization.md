This project builds a **real-time visualization system for magnetic sensor arrays** used in magnetic pose estimation and tactile-sensing experiments.

The system processes streaming sensor data from an **85-sensor magnetic array (17×5)** connected through a serial interface.

Main features include:

- Real-time magnetic field visualization
- Sensor array calibration
- Geomagnetic background compensation
- Data acquisition with Python and PyQt GUI
- Debugging support for soft linear magnet and MIMMS pose-estimation experiments

The visualization system helps researchers analyze magnetic field patterns, inspect background compensation, and debug pose estimation algorithms before connecting them to inverse modeling pipelines.
