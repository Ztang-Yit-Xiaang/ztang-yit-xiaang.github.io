This project develops **Rime-based input methods for Wenzhounese and Rui’anese language technology**, with a focus on computational access for underrepresented Southern Wu varieties.

The work includes a public Rui’anese typing method and a local Wenzhounese/Rui’an extension built around phonetic schemas, dictionary files, fuzzy-sound support, simplified/traditional output options, and pinyin reverse lookup.

Major components include:

- Design of phonetic transcription systems for Wenzhounese and Rui’anese
- Rime input schema implementation
- Dictionary construction for dialectal vocabulary
- Mapping between phonetic input and Chinese characters
- OCR- and reference-book-supported dictionary expansion
- Cross-platform deployment through the Rime input method engine

Future directions include exploring **language models and LLM-based tools** to improve typing efficiency and dialect processing.

The project contributes to the **digital preservation of minority languages and dialects**.
