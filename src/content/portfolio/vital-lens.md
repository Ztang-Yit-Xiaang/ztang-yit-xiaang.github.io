## A draft should remain editable
Vital Lens explores a camera-first journal for activities, meals, and daily context. The Expo prototype includes editable entries, local storage, and backend API integration code. The central interaction is to review and correct a draft before treating it as a saved record.

## My contribution
I implemented the app and its logging workflows and backend integration code. The repository also retains an earlier static web prototype and development instructions. This portfolio review inspected the source; it did not certify an installed iPhone build, a running backend, recognition accuracy, or the reliability of health-related estimates.

## Try the original browser prototype
The embedded interface is the original static web prototype from the repository, with its HTML, styles, and JavaScript preserved. Visitors can change exercise type, add a sample session, and inspect the local journal. The captured preview shows those actual controls in use.

Its preset dashboard values and recognition responses are hard-coded demonstration data. This portfolio copy does not contact an AI backend or load personal records. It illustrates the original interaction and correction workflow without establishing recognition or health-measurement accuracy.
